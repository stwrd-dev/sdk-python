# Security policy

## Supported versions

While the version is below 1.0, only the latest minor release of `stwrd-auth` receives security fixes. Upgrade to it before reporting a problem you found in an older release.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the **Security** tab of [https://github.com/stwrd-dev/sdk-python](https://github.com/stwrd-dev/sdk-python) and choose **Report a vulnerability**. Do not open a public issue, pull request or discussion for a vulnerability.

Include the version, what an attacker can do, and the steps or code that reproduce the problem.

- You will receive an acknowledgement within 5 business days.
- Reports are handled under coordinated disclosure. The default disclosure period is 90 days from the report, or until a fix is released, whichever comes first.

## Scope

This policy covers the `stwrd-auth` package published from this repository.

The hosted stwrd service is out of scope. To report a problem with it, use the contact published at [https://stwrd.dev](https://stwrd.dev).
